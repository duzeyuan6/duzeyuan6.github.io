# Zeyuan Du — Academic Homepage

基于 [Luka Homepage Template](https://github.com/wzsyyh/luka-homepage-template) 定制的个人学术主页，内容来自 Zeyuan Du 的 CV，采用深蓝色响应式设计。

## 本地预览

直接打开 `index.html`，或在本目录运行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 发布到 GitHub Pages

1. GitHub 仓库名必须为 `<你的 GitHub 用户名>.github.io`。
2. 将本目录全部文件推送到仓库的 `main` 分支。
3. 在仓库 `Settings → Pages` 中选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`。
4. 发布地址为 `https://<你的 GitHub 用户名>.github.io/`。

页面入口为 `index.html`，配色与布局在 `assets/css/theme-luka.css`，公开下载版简历位于 `assets/cv/Zeyuan-Du-CV.pdf`。
